How to Solve Operating Systems & Computer Networks Assignments

Operating systems and computer networking assignments demand both theoretical depth and mathematical accuracy. Learn how to solve CPU scheduling Gantt charts, paging calculations, deadlock Banker's algorithms, and CIDR subnetting math.

Operating Systems (OS) and Computer Networks (CN) are two of the most conceptually rigorous subjects in university computer science programs. They bridge the gap between abstract software applications and physical silicon and transmission hardware.

Unlike general programming coursework where you can test code iteratively, OS and Networking assignments frequently involve theoretical problem sets: drawing CPU scheduling Gantt charts, calculating page faults under LRU replacement, running Dijkstra's link-state routing, and subnetting IP addresses. This guide provides step-by-step problem-solving templates for these core problem types.

1. Operating Systems: CPU Scheduling & Deadlocks

University OS assignments test resource management through process scheduling algorithms and concurrency controls:

CPU Scheduling Gantt Charts
  • Algorithms: FCFS, Shortest Job First (SJF / SRTF), Priority, and Round Robin (RR with time quantum q).
  • Required Metrics: Always compute Waiting Time (Turnaround - Burst) and Turnaround Time (Completion - Arrival) across all processes.
Deadlocks & Banker's Algorithm
  • Coffman Conditions: Mutual exclusion, Hold and wait, No preemption, and Circular wait.
  • Banker's Algorithm: Construct the Need Matrix = Max - Allocation to verify if a safe execution sequence exists without deadlock.

2. Computer Networks: Step-by-Step CIDR Subnetting Calculations

Subnetting questions appear on virtually every networking exam and assignment. Follow this foolproof 4-step subnetting method:

Problem: Given network 192.168.10.0/24, design subnets supporting at least 25 hosts each.

  1. Determine Host Bits (h): Formula is 2h - 2 ≥ required hosts. For 25 hosts: 25 - 2 = 30 ≥ 25. Thus, h = 5 bits.
  2. Calculate New Subnet Mask: Total IPv4 bits = 32. Subnet bits = 32 - h = 32 - 5 = /27 (Mask: 255.255.255.224).
  3. Calculate Block Size (Step Size): Block size = 256 - 224 = 32.
  4. List Subnet Ranges:
    • Subnet 1: 192.168.10.0/27 → Usable Hosts: .1 to .30 (Broadcast: .31)
    • Subnet 2: 192.168.10.32/27 → Usable Hosts: .33 to .62 (Broadcast: .63)
    • Subnet 3: 192.168.10.64/27 → Usable Hosts: .65 to .94 (Broadcast: .95)
